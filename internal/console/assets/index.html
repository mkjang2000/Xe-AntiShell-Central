탐지 설정

확장 규칙은 웹 출처의 도구·인터프리터·임시 경로 실행을 탐지합니다. 확장 규칙을 켜면 기본 웹셸 규칙을 포함해 모든 경보가 탐지 전용으로 기록됩니다.

전역 규칙은 웹 출처와 관계없이 동작하며 탐지 전용입니다. 모든 root 실행 이력과 경보는 구분됩니다. 권한 변경 센서의 실제 수신 여부는 에이전트 기능 상태에서 확인하세요. 구형 에이전트에는 먼저 업데이트가 필요합니다.

탐지 대상·셸·예외 목록 편집

목록은 한 줄에 한 항목씩 입력합니다. 실행 파일은 경로 없이 이름만 입력하세요.

서비스별 규칙과 임시 예외

enabled는 사용 중인 프로필의 규칙을 허용하고, disabled는 해당 서비스에서만 규칙을 끕니다. suppress_until에는 사유와 UTC 만료 시각이 필요합니다. 설정을 지우면 프로필의 기본 판정이 적용됩니다.

사용 가능한 규칙 ID

서비스별 파일·TCP 범위

위 웹 서비스 목록에 있는 이름을 사용하세요. 빈 배열 []은 모든 서비스의 파일·TCP 규칙을 끕니다. 선택을 해제하면 호스트 YAML을 사용합니다.

대응 방식·안전 조건

탐지 전용은 프로세스를 종료하지 않습니다.

에이전트 제거와 정책 유효 기간

관리형 에이전트의 일반 제거에는 일회용 중앙 승인이 필요합니다. 유효 기간은 배포 시점부터 계산하며, 기한이 지나면 기존 탐지를 유지하고 자동 대응을 중단합니다.

에이전트 파일 무결성

새 정책 리비전을 배포하면 실행 파일 4개와 systemd 유닛 3개의 측정값을 승인된 RPM과 비교합니다. 사이트 YAML은 기준값을 입력해야 일치 여부를 확인할 수 있습니다.

추가 무결성 초안 · 읽기 전용

TPM 필수 조건, 임의 경로, 강제 무결성 검증은 중앙에 초안으로 보관합니다. 지원 에이전트가 수행하는 현재 검사는 위의 에이전트 파일 무결성에서 설정합니다.

에이전트 설정 Agent Configuration

자원 모니터링

주기 5~3,600초, 프로세스 1~2,000개 범위에서 지정합니다. 모니터링을 끄면 자원 정보 수집을 중단하고 연결과 정책 적용 상태는 계속 보고합니다. 보고 간격이 2분 이상이면 센트럴에서 수신 지연으로 표시되거나 새 규칙의 지원을 확인할 수 없을 수 있습니다.

호스트 보안 경계 Host Security Boundary

조회 전용

에이전트는 등록 시 받은 키로 정책 서명과 대상 등록을 확인합니다. 아래에는 중앙의 등록 기록과 선택한 호스트가 보고한 상태를 표시합니다.

호스트의 신뢰 CA, 정책·업데이트 검증 키, root 작업자 권한, 복구 승인 정보, 중앙 연결 주소, SELinux 모드는 하트비트에 미보고됩니다.

에이전트 설치 토큰

단일 대상

등록할 에이전트 ID에만 유효한 설치 토큰을 발급합니다. 설치 마법사에 토큰 하나를 붙여 넣으면 중앙에 연결할 수 있습니다. 비밀값은 발급 직후 한 번만 표시됩니다.

설치 토큰 발급 준비 상태를 확인하고 있습니다.

에이전트 제거 승인

일회용

서버에서 생성한 제거 요청(챌린지)에 승인 JSON을 발급합니다. 이 JSON이 일회용 제거 승인값(OTP)입니다.

현재 등록과 일치하는 요청만 승인합니다.
대상 서버에서 sudo sentinel managed challenge 실행 후 challenge 값 또는 출력 JSON을 붙여 넣으세요.

등록 해지

연결 권한 무효화

등록 해지는 현재 인증서를 무효화하여 중앙 연결을 차단합니다. 서버에 설치된 에이전트를 제거하지 않습니다.

중앙 관리 활동

날짜·에이전트·유형·검색어를 전체 중앙 감사 기록에 적용합니다. 발급 비밀값은 다시 조회할 수 없습니다.
