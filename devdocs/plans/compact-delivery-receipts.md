# 센트럴 수신 영수증 용량 관리

## 목표와 적용 범위

일반 관측 본문이 한 시간 뒤 만료되어도 센트럴은 동일 순번의 재전송과 다른 순번으로 되풀이된 ID를 검증해야 한다. RPM 16은 순번마다 에이전트, 등록, 스풀, 종류, 기록 ID와 64자 해시를 저장하고 긴 복합 키를 보조 인덱스에 다시 쓴다. 이 변경은 새 영수증 한 건의 저장 공간과 만료 후 파일 반환 작업의 I/O를 줄인다. 에이전트 바이너리, 배치 크기 및 전송 형식은 그대로 사용한다.

## 설계와 호환성

- 스키마 4는 스풀별 커서에 안정적인 정수 키와 전환 시점의 마지막 ACK를 기록한다. 마이그레이션의 복사 대상은 스풀 커서다. 대량의 과거 영수증과 관측 본문은 기동 시 다시 쓰지 않는다.
- 새 영수증은 스풀 키, 순번, 검증값 32바이트를 복합 기본 키 테이블에 저장한다. 검증값은 도메인 접두사, 바이트 길이를 명시한 종류 및 기록 ID, 원본 정규화 페이로드의 SHA-256을 순서대로 연결한 뒤 계산한 SHA-256이다. 종전 순번의 재전송에는 원래 영수증을 사용한다. 배치 전체가 검증되고 데이터와 커서가 함께 커밋된 뒤 ACK를 반환한다.
- 다른 스풀이나 순번에서 같은 기록 ID가 들어올 때의 검증은 기존 기록 및 만료 다이제스트를 사용한다. 탐지, 감사와 그 근거의 보존 기간도 기존 정책을 따른다. 영구 메타데이터의 증가율을 줄이며, 전체 DB 크기에 고정 상한을 부여하는 기능은 별도 정책이 필요하다.
- 회수 가능한 페이지는 수신 쓰기에 우선 재사용하고, 파일 축소는 밀린 만료 처리를 따라잡은 후 최소 16 MiB의 빈 페이지를 남기고 분당 한 번 최대 256 KiB의 페이지를 반환한다. 100ms의 별도 시도 기한을 둔다. 페이지 반환 과정에서 SQLite가 부가 WAL 프레임을 쓸 수 있다.
- 로컬 용량 조회는 읽기 전용으로 DB/WAL 파일, 재사용 가능 페이지, 파일시스템 가용량, 만료 지연, 누적 구·신 영수증 순번 수를 보여 준다. 영수증 수는 스풀 커서의 누적 ACK와 전환 경계에서 계산한다. 입력 경로에 계량 쓰기를 추가하지 않는다.

## 검증과 롤백

스키마 3 샘플에서 구형·신형 영수증을 섞어 재전송하고, 순번 충돌, 종류·ID 변경, 배치 롤백, 재기동과 VACUUM 후 정수 키 보존을 검사한다. 같은 입력으로 실제 수신과 만료를 실행해 사용 중인 페이지, WAL 프레임 바이트와 CPU 시간을 비교한다. 독립 에이전트 mTLS 통합 테스트로 기존 클라이언트 호환성을 확인한다.

스키마 3 전용 바이너리는 스키마 4를 열 수 없다. 운영에 적용할 때는 이전 복구점과 이후의 ACK 차이를 고려해야 한다. 운영 DB 전체 재작성이나 기동 시 일괄 변환을 전제로 하지 않는다.

## 격리된 비교 측정

네 에이전트의 일반 관측 총 1,024건을 32건씩 커밋하고 한 시간 경과에 해당하는 시각에서 128건씩 만료시켰다. 같은 Linux 호스트에서 같은 SQLite WAL 및 FULL 동기화 설정으로 버전별 4회 교차 실행한 중앙값이다. 빈 DB에서 시작해 수신·만료 한 주기를 측정했다.

| 일반 관측 1건당 | 스키마 3 | 스키마 4 |
| --- | ---: | ---: |
| 만료 뒤 사용 중인 DB 페이지 순증 | 464 B | 168 B |
| 빈 페이지를 포함한 체크포인트 후 DB 파일 순증 | 1,964 B | 1,664 B |
| 수신 및 만료 트랜잭션의 논리 WAL 바이트 | 10,131 B | 9,524 B |
| 수신 트랜잭션의 논리 WAL 바이트 | 6,912 B | 6,305 B |
| 센트럴 프로세스 CPU 시간 | 380.26 µs | 380.71 µs |

CPU 측정에는 체크포인트 및 파일 반환이 제외된다. WAL 측정 동안 자동 체크포인트를 꺼서 새로 생성된 프레임을 측정했다. 실제 운영 파일시스템의 기록 바이트, 장기 증가율, 탐지·감사 비중은 별도 측정 대상이다. 재현 명령은 다음과 같다.

```sh
GOMAXPROCS=2 go test -run '^$' -bench '^BenchmarkOrdinaryHistoryStorage$' -benchtime=1x -count=4 ./internal/central
```
